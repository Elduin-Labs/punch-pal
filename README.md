# Punch Pal

A friend who looks like a player. It runs up to you and punches you, and you fly
255 blocks away. You always land safely on the ground, and it never hurts.

Find the **Punch Pal Spawn Egg** in the Spawn Eggs tab.

- It chases the nearest player and punches when it gets close.
- You land on safe ground: never in lava, never in the void.
- Players can't hurt it. It's a friend.

Made by Elduin. Fabric, for Minecraft 1.21.11 and 26.2.
